# RF-Based Robot Car Communication System

This project demonstrates wireless control of a robot car using **Arduino Nano** and **433 MHz RF modules**.  
It uses **RadioHead RH_ASK** library for communication and controls a robot car through two BLDC motor controllers.

---

## 🚀 Features
- Wireless communication (433 MHz RF module).
- Separate transmitter and receiver systems.
- Robot car controlled with **2x BLDC motors** and **ZS-X11H controllers**.
- Smooth acceleration and deceleration.
- Steering implemented by adjusting motor speeds.
